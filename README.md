 r# Shipment-Price-Prediction-ML-Project

## Before you run this project make sure you have MongoBD Allas account and you have the shipping dataset into it.

Step 1. Cloning the repository.

```
git clone https://github.com/jubayerhu1/Shipment-Price-Prediction-ML-Project.git
```
Step 2. Crate a code environment .

```
conda create  shipment venv pythotn=3.11 -y 
```

```
conda activate shipment
```

Step 3. Install the requirements

```
pip install -r requirements.txt
```

```
pip freeze > requirements_dev.txt
```
